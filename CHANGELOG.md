## [1.0.0-alpha] - 2026-10-05

### Added
- Enterprise repository architecture and baseline documentation.
- Requirements traceability matrix covering BRD v1.0 (FR-01 to FR-12).
- CI/CD workflow configuration for GitHub Actions (`lint`, `test`, `build`).
- Automated CodeQL security scanning and dependency vulnerability checks.
- Structured GitHub Issue Forms for bug reports and feature requests.
- Standardized Pull Request template with stakeholder review checklist.
- C4 Architecture design document with Bengali-to-English NLP search pipeline.
- Docker Compose configuration for local PostgreSQL database and Redis.
