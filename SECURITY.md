# Security Policy

## Supported Versions

Only the latest active release branch receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The engineering team takes the security of the **Unified Course App** seriously. If you discover a security vulnerability, please follow our coordinated disclosure policy:

1. **Do NOT open a public GitHub issue.**
2. Send a detailed report to the core security team at `security@unifiedcourseapp.com` (or create a [Private Security Advisory](https://github.com)).
3. Include:
   - Type of issue (e.g. CSRF, SQL Injection, Open Redirect, Auth Bypass)
   - Step-by-step reproduction instructions or Proof-of-Concept (PoC)
   - Impact assessment on learner data or course catalog

### Response Timeline
- **Initial Response:** Within 24 hours.
- **Triage & Status Update:** Within 48 hours.
- **Fix & Disclosure:** Coordinated release within 14 business days.
